Which one fits

GlobaLeaks is the mature reference among open source whistleblowing platforms. The other three answer narrower questions.

PickWhen
GlobaLeaks You need many languages or right-to-left scripts, a questionnaire builder, or several channels per site. You want years of track record and published audits, or a managed service instead of your own server.
OpenWhistle You are a German employer or authority and want the HinSchG case workflow built in: both deadlines per case, reminders, audit log, 3-year deletion. You already run Docker Compose or Kubernetes with PostgreSQL.
SecureDrop You are a newsroom or NGO receiving documents from sources, and can run dedicated hardware with an air-gapped viewing station.
Hush Line You are a person or small team who wants an encrypted tip line without running a server.

Managed GlobaLeaks

Some companies run GlobaLeaks for you. One example is opensource-hinweisgeberportal.de by splice digital GmbH [5].

  • The software is GlobaLeaks; the provider operates the server.
  • Hosting is in German data centres, on request on dedicated hardware.
  • Packages come with a 30-day money-back guarantee; the home page names no price.

The trade is the same for any managed service: someone else runs the server and processes the reports for you.

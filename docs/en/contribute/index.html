Contribute

OpenWhistle is built in spare time, by one maintainer. These are the places where your help counts most.

Where a review helps most

  • Encryption and key rotation: can a report be read without the key, or lost during a rotation?
  • The anonymity layers: does any path still carry an IP address into a log, a session or the database?
  • The identity reveal: can anyone see a reporter's name without an audited reason?

A first issue

Issues labelled good first issue are small and self-contained. CONTRIBUTING.md shows the setup, the checks and the commit style.

Translate

The app speaks English, German, French and Brazilian Portuguese. A language is one JSON file in app/locales/. CONTRIBUTING.md says what a locale change touches and which review a translation must pass.

Sponsor

GitHub Sponsors pays for the time this spare-time project takes.

Found a vulnerability?

Report it privately, as the security page describes.

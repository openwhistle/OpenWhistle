LDAP / Active Directory login

Admins can also sign in with corporate LDAP. The first login creates an AdminUser (no local password) with the Case Manager role; an admin promotes it if needed. TOTP enrollment still follows, as for every account.

  • Accounts with a local password, such as the one the setup wizard created, keep signing in with it.
  • A directory user whose name a local account already has is refused, never merged into it.
  • The username comes from LDAP_ATTR_USERNAME. An entry without it is refused.

LDAP uses python-ldap (the OpenLDAP client) and S3 storage uses boto3: optional extras, both in the container image. From source, install libldap2-dev libsasl2-dev, then pip install '.[ldap,s3]'.

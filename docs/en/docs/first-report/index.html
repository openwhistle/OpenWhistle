Your first report

Right after the install, send one test report through your own installation and follow it from both sides.

1. Submit it as the whistleblower

  1. Open your installation's root URL in a private window. No account is needed.
  2. Choose Anonymous, then a category, and write a test description of at least 10 characters.
  3. Submit, then save the case number and the PIN. They are shown once.

Every step of the form: Whistleblower guide.

2. Acknowledge it as the reporting office

  1. Sign in at /admin with the account the setup wizard created, then your TOTP code.
  2. Open the test report on the dashboard. Its 7-day deadline is already running.
  3. Click Acknowledge report, then reply through the anonymous channel.

The case page in full: Admin guide.

3. Read the reply as the whistleblower

Open /status, enter the case number and PIN, and read the reply. The 3-month feedback deadline now counts from the acknowledgement.

4. Delete the test report

Delete report needs a second admin to confirm. Create a second account first, or keep the test report: four-eyes deletion.

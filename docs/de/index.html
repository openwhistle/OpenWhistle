Funktionen

Was jede Seite bekommt

Für Hinweisgebende
ZugangFallnummer und eine PIN im UUID4-Format, einmal angezeigt. Kein Konto, keine E-Mail-Adresse.
ModusAnonym oder vertraulich: Name und Kontakt verschlüsselt, für die Fallbearbeitung erst nach protokolliertem Grund sichtbar
RückfragenAntworten lesen und Nachrichten senden unter /status, mit Fallnummer und PIN
Für die Meldestelle
FallarbeitStatus, Zuweisung, interne Notizen, verknüpfte Fälle, PDF-Export
HinweiseAuf Wunsch E-Mail- und Webhook-Zusammenfassungen und Fristerinnerungen
Für den Betrieb
AnmeldungPasswort, LDAP oder OIDC, danach immer TOTP. Die Einrichtung ist Pflicht.
VerschlüsselungJede Meldung hat einen eigenen Datenschlüssel; der Hauptschlüssel liegt nie in der Datenbank
Sprachen5 Sprachen: Deutsch, Englisch, Französisch, Spanisch, Portugiesisch (Brasilien)

Demo oder Installation

Erst testen, dann selbst betreiben

Die öffentliche Demo meldet Sie mit vorausgefüllten Zugangsdaten an und wird alle 6 Stunden geleert. Geben Sie dort nie eine echte Meldung ein.

Die eigene Installation braucht drei Befehle und eine Änderung in der .env. Danach legt der Assistent unter /setup das erste Konto an.

Demo öffnen → Installationsanleitung (englisch) →
bash — openwhistle setup
$ git clone https://github.com/openwhistle/OpenWhistle.git
$ cd OpenWhistle && cp .env.example .env
# .env: COMPOSE_FILE, SECRET_KEY, DATABASE_URL, REDIS_URL eintragen
$ docker compose up -d

# Dann https://localhost/setup öffnen, mit dem Token aus dem App-Log
FAQ

Häufig gestellte Fragen

Welche Hinweisgebersystem-Software ist kostenlos?
Ohne Lizenzkosten sind zum Beispiel die Open-Source-Systeme OpenWhistle (GPL-3.0) und GlobaLeaks (AGPL-3.0). Beide betreiben Sie auf Ihrem eigenen Server. Den Vergleich mit Quellen bietet der Artikel Hinweisgebersystem-Anbieter im Vergleich 2026.
Ist OpenWhistle Open Source?
Ja, OpenWhistle ist Open Source unter der GNU General Public License v3.0. Der gesamte Quellcode liegt öffentlich auf GitHub. Sie dürfen ihn prüfen, ändern und kommerziell einsetzen.
Kann ich das Hinweisgebersystem selbst hosten?
Ja, OpenWhistle gibt es nur selbst gehostet: Sie betreiben es mit Docker Compose oder Helm auf Ihrem Server. Einen gehosteten Dienst des Projekts gibt es nicht. Die Installation beschreibt die Dokumentation.
Welche Hinweisgebersysteme bieten EU-Hosting?
Jedes selbst gehostete System läuft dort, wo Ihr Server steht, also auch in der EU. Das gilt für OpenWhistle und GlobaLeaks. Unter den Diensten nennen etwa das Hinweisgeberportal OpenSource und WhistlePort Rechenzentren in Deutschland, Stand 27. September 2026 (Hinweisgebersystem mit EU-Hosting).
Ist OpenWhistle DSGVO-konform?
Die Software unterstützt einen DSGVO-konformen Betrieb; ob der Betrieb konform ist, verantworten Sie als Betreiber. OpenWhistle speichert keine IP-Adressen, verschlüsselt Meldungen und löscht abgeschlossene Fälle automatisch. Verarbeitungsverzeichnis, Vertrag mit dem Hoster und gegebenenfalls eine Datenschutz-Folgenabschätzung bleiben Ihre Aufgabe.
Verschlüsselt OpenWhistle die Meldungen?
Ja. Jede Meldung hat einen eigenen Datenschlüssel, mit dem Text, Nachrichten und Anhänge verschlüsselt gespeichert werden. Der Hauptschlüssel liegt nie in der Datenbank. Zum Browser läuft die Verbindung über TLS.
In welchen Sprachen gibt es OpenWhistle?
Die Oberfläche gibt es auf Deutsch, Englisch, Französisch, Spanisch und Portugiesisch (Brasilien). Sie folgt der Sprache des Browsers, bis die Person selbst eine wählt.
Ist OpenWhistle wirklich kostenlos?
Ja. Die Software steht unter der GNU General Public License v3.0. Es gibt keine bezahlte Ausgabe, keine Funktion hinter einer Bezahlschranke und kein Abonnement. Kosten entstehen für Ihren Server und den Betrieb.
Was kostet ein kostenloses Hinweisgebersystem wirklich?
Die Lizenz kostet 0 €. Es bleiben ein Server, Zeit für Updates und Backups und die Arbeit der Meldestelle selbst. Das Gesetz verlangt zusätzlich einen mündlichen Kanal per Telefon (§ 16 Abs. 3 HinSchG).
Erfüllt OpenWhistle das HinSchG?
OpenWhistle deckt den Meldekanal in Textform ab: Eingangsbestätigung in 7 Tagen, Rückmeldung in drei Monaten, Kontakt zur hinweisgebenden Person, Vertraulichkeit und Löschung. Den telefonischen Kanal, die Besetzung und die Folgemaßnahmen organisieren Sie selbst.
Ist der Hinweisgeber wirklich anonym?
OpenWhistle speichert keine IP-Adresse, weder in der Datenbank noch in Protokollen. nginx entfernt die IP-Header, die App verwirft die Adresse, das Schema hat keine IP-Spalte. Zeiten des Hinweisgebers werden nur auf den Tag genau gespeichert.
Für wen ist OpenWhistle gedacht?
Für Beschäftigungsgeber mit in der Regel mindestens 50 Beschäftigten, bestimmte Finanzunternehmen jeder Größe und öffentliche Stellen. Die GPL-3.0 erlaubt die kommerzielle Nutzung ausdrücklich.
Welche technischen Voraussetzungen gibt es?
Docker 24 oder neuer mit Compose v2, 1 vCPU, mindestens 512 MB RAM (1 GB empfohlen) und 5 GB Speicher. Dazu eine Domain mit HTTPS-Zertifikat. PostgreSQL 18 und Redis 8 sind im Compose-Stack enthalten.
Gibt es kommerziellen Support?
Nein. Hilfe gibt es über GitHub Issues. Das Projekt entsteht in der Freizeit. Wer Betrieb und Support einkaufen möchte, findet verwaltete Angebote im Vergleichsartikel.
Wie unterscheidet sich OpenWhistle von anderen Hinweisgebersystemen?
OpenWhistle läuft nur selbst gehostet und kostet keine Lizenz. Der Quellcode ist öffentlich. Einen Vergleich mit GlobaLeaks und kommerziellen Anbietern, mit Quellen und Datum, bietet der Artikel „Hinweisgebersystem-Anbieter im Vergleich 2026“.
Unterstützt OpenWhistle Single Sign-on und LDAP?
Ja. Der erste Faktor kann ein Passwort, LDAP beziehungsweise Active Directory oder ein OIDC-Anbieter sein. Der TOTP-Code bleibt immer Pflicht. Seit 2.1 verknüpft jede Person ihr Konto unter „Mein Konto“ selbst mit dem Anbieter.
Kann ich OpenWhistle für mehrere Standorte oder Gesellschaften nutzen?
Ja. Ab Version 1.0.0 unterstützt OpenWhistle Multi-Tenancy. Verwaltbar ist sie seit 2.0.1, weil erst dort das erste Konto Superadmin wird; seit 2.1 wählt der Superadmin für jedes neue Konto die Organisation. Jede Organisation hat eigene Meldungen, Kategorien, Standorte, Konten und einen eigenen Meldelink.

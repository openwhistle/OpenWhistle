EU-Whistleblower-Richtlinie

Die Richtlinie (EU) 2019/1937 regelt interne Meldekanäle in der ganzen EU. Jeder Mitgliedstaat setzt sie in eigenes Recht um; in Deutschland ist das das HinSchG. Diese Seite ist eine Übersicht, keine Rechtsberatung.

Der verbindliche Text steht auf EUR-Lex.

Mitmachen

OpenWhistle entsteht in der Freizeit, mit einem einzigen Maintainer. Hier zählt Ihre Hilfe am meisten.

Wo ein Review am meisten hilft

Die verlinkte Dokumentation ist englisch.

  • Verschlüsselung und Schlüsselwechsel: Lässt sich eine Meldung ohne den Schlüssel lesen, oder geht sie beim Wechsel verloren?
  • Die Anonymitätsschichten: Trägt irgendein Weg noch eine IP-Adresse in ein Log, eine Session oder die Datenbank?
  • Die Offenlegung der Identität: Kann jemand den Namen von Meldenden ohne protokollierten Grund sehen?

Ein erstes Issue

Issues mit dem Label good first issue sind klein und in sich abgeschlossen. CONTRIBUTING.md (englisch) zeigt die Einrichtung, die Prüfungen und den Commit-Stil.

Übersetzen

Die App spricht Englisch, Deutsch, Französisch, Spanisch und brasilianisches Portugiesisch. Eine Sprache ist eine JSON-Datei in app/locales/. CONTRIBUTING.md (englisch) sagt, was eine Änderung an einer Sprachdatei berührt und welche Prüfung eine Übersetzung bestehen muss.

Sponsern

GitHub Sponsors bezahlt die Zeit, die dieses Freizeitprojekt kostet.

Eine Schwachstelle gefunden?

Melden Sie sie vertraulich, wie es die Sicherheitsseite beschreibt.

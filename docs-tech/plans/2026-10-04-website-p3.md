# Website P3 (content) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** openwhistle.net says what OpenWhistle is, for whom, and how to check it: docs as one page per task with
search, compliance, security and contribute pages in English and German, an imprint and a privacy policy that
describe exactly this setup, and per-page OG images, structured data and feeds.

**Architecture:** `scripts/build_site.py` gains a second layout (`docs`), a settings table generated from
`docs/_data/config.yml`, a Pagefind index, OG images, Atom feeds and `security.txt`. The one-pager
`docs/en/docs/index.html` is split by a one-off script that moves blocks byte for byte. Content pages are plain
HTML with front matter, like every page since P1.

**Tech Stack:** Python 3.14, Jinja2, markdown-it-py, fontTools, Pillow, Pagefind 1.5 from PyPI
(`pagefind[extended]`, already in the `site` group), Playwright for the e2e checks.

**Spec:** `docs-tech/specs/2026-10-04-website-p3-design.md`, refining P3 of
`docs-tech/specs/2026-10-01-website-redesign-design.md`.

## Global Constraints

- English everywhere in code, comments and docs; German only in German pages (`docs/de/…`, `/impressum/`).
- No request to another host from any page; fonts from `docs/fonts/` only.
- Diagrams only as draw.io; a label never sits on a line.
- Title 10–60 characters, description 120–160, both unique across the site (`tests/test_seo.py`).
- Every sentence ≤ 30 words, page average < 18 (`tests/test_docs_prose.py`).
- Every internal link and fragment resolves, or the build fails.
- Commit messages never mention Claude Code; every commit ends with the session's attribution trailer.
- One PR for all of P3 (P3-1); no release (P3-9); app changes go under CHANGELOG `[Unreleased]`.
- Every new guard goes through `scripts/mutation_audit.py` and goes RED.
- Standing checks in every task that touches a page: axe in both themes, forced colours, one theme twin per figure,
  360 px without sideways scroll, and a look at the page in a browser, dark theme first.
- Tests run with `.venv/bin` on `PATH` (otherwise alembic is missing and DB tests error) against throwaway
  PostgreSQL 18 and Redis 8 containers on 127.0.0.1:55432 and :56379.

## Review Focus

1. **An old deep link** (`/docs.html#own-account`, `/en/docs/#helm`, a bookmark from a blog post): it lands on the
   section, not on the docs start page. Task 2 pins all 47 ids; Task 3 pins the browser path.
2. **A docs page on a phone**: 30 sidebar links must not push the content a screen down. Task 3 pins a closed menu
   at 390 px.

   how-to page shows the same row as the reference. Task 1 and Task 2.
4. **Search with JavaScript off, or typing `/` inside a field**: no dead button; `/` in an input types a slash.
   Task 4.
5. **The app footer outside demo mode**: an operator's own installation must not link openwhistle.net's imprint.
   Task 8.

```python
# need -> (CSS class suffix, label), exactly as the hand-written tables had them
_NEED = {
    "required": ("yes", "Required"),
    "recommended": ("no", "Recommended"),
    "optional": ("no", "Optional"),
}
_CONFIG_MARKER = re.compile(r'<div data-config="([\w-]+)"></div>')


def load_config(src: Path) -> dict[str, Any]:
    """docs/_data/config.yml: every setting once, in groups (tests/test_config_documented.py)."""
    path = src / "_data" / "config.yml"
    return _yaml(path) if path.is_file() else {"intro": "", "groups": []}


def config_table(group: dict[str, Any]) -> str:
    rows = []
    for setting in group["settings"]:
        cls, label = _NEED[setting["need"]]
        rows.append(
            f'<tr><td><code class="env-key">{setting["name"]}</code></td>'
            f'<td><span class="env-required env-req-{cls}">{label}</span></td>'
            f"<td>{setting['description']}</td><td>{setting.get('default', '—')}</td></tr>"
        )
    return (
        '<div class="table-scroll">\n'
        f'<table class="env-table" aria-label="Settings: {html.escape(group["title"])}">\n'
        '<thead><tr><th scope="col">Variable</th><th scope="col">Required</th>'
        '<th scope="col">Description</th><th scope="col">Default</th></tr></thead>\n'
        "<tbody>\n" + "\n".join(rows) + "\n</tbody>\n</table>\n</div>\n"
    )


def fill_config(rel: Path, content: str, groups: dict[str, dict[str, Any]]) -> str:
    def table(found: re.Match[str]) -> str:
        if found.group(1) not in groups:
            raise BuildError(f"{rel}: no group {found.group(1)!r} in _data/config.yml")
        return config_table(groups[found.group(1)])

    return _CONFIG_MARKER.sub(table, content)


def _configuration(src: Path) -> str:
    config = load_config(src)
    parts = ["<h1>Configuration</h1>", config["intro"]]
    for group in config["groups"]:
        title = html.escape(group["title"])
        guide = html.escape(group["guide"])
        parts += [
            f'<h2 id="{group["id"]}">{title}</h2>',
            f'<p>Explained in <a href="{group["page"]}">{guide}</a>.</p>',
            config_table(group),
        ]
    return "\n".join(parts) + "\n"


# generator name -> (function, the file its output comes from)
GENERATORS: dict[str, tuple[Callable[[Path], str], Path]] = {
    "changelog": (_changelog, ROOT / "CHANGELOG.md"),
    "configuration": (_configuration, DOCS / "_data" / "config.yml"),
}


def _slug(text: str) -> str:
    return re.sub(r"[^a-z0-9]+", "-", re.sub(r"<[^>]+>", "", text).lower()).strip("-")


def add_heading_ids(text: str) -> str:
    """Markdown headings get ids, so "on this page" can link them."""

    def add(found: re.Match[str]) -> str:
        level, attrs, inner = found.groups()
        if "id=" in attrs:
            return found.group(0)
        return f'<h{level}{attrs} id="{_slug(inner)}">{inner}</h{level}>'

    return re.sub(r"<h([23])([^>]*)>(.*?)</h\1>", add, text, flags=re.S)
```

```python
def docs_context(

        {"label": "Documentation", "href": flat[0][1]["href"]},
    ]
    if here:
        crumbs += [
            {"label": flat[here][0], "href": None},
            {"label": flat[here][1]["label"], "href": None},
        ]
    generator = page.meta.get("generated")
    rel = (
        GENERATORS[generator][1].relative_to(ROOT).as_posix()
        if generator
        else f"docs/{page.source.as_posix()}"
    )
    return {
        "sidebar": sidebar,
        "toc": [
            (anchor, Markup(re.sub(r"<[^>]+>", "", inner).strip()))
            for anchor, inner in _TOC.findall(page.content)
        ],
        "prev": flat[here - 1][1] if here > 0 else None,
        "next": flat[here + 1][1] if here + 1 < len(flat) else None,
        "crumbs": crumbs,
        "edit_url": f"{site['github_url']}/edit/main/{rel}",
        "anchors": data["docs_anchors"] if here == 0 else {},
    }


def breadcrumb_jsonld(docs: dict[str, Any], page: Page, site: dict[str, Any]) -> dict[str, Any]:
    """Linked crumbs, then the page itself; a group heading is no URL, so it is left out."""
    linked = [c for c in docs["crumbs"] if c["href"] and c["href"] != page.url]
    names = [*(c["label"] for c in linked), docs["crumbs"][-1]["label"]]
    urls = [*(c["href"] for c in linked), page.url]
    return {
        "@context": "https://schema.org",
        "@type": "BreadcrumbList",
        "itemListElement": [
            {"@type": "ListItem", "position": i, "name": name, "item": site["base_url"] + url}
            for i, (name, url) in enumerate(zip(names, urls, strict=True), 1)
        ],
    }
```

```python
    """GitHub Pages cannot send a 301; until P5 a stub stands in for each one.

    The script keeps the #fragment, which a meta refresh would drop. "/" is a
    stub to the default language on Pages; from P4 on nginx negotiates it.
    An old URL that is not HTML (e.g. /hinschg_reference.md) cannot run a
    script, so it keeps serving the bytes it served, frozen in _legacy/.
    """
    stubs = {"/": f"/{site['default_language']}/", **redirects}
    written: dict[Path, str] = {}
    for old, new in stubs.items():
        if not old.endswith(("/", ".html")):
            legacy = src / "_legacy" / unquote(old).lstrip("/")
            if not legacy.is_file():
                raise BuildError(
                    f"_data/redirects.yml: {old} needs its frozen copy at _legacy{old}"
                )
            dest = out / unquote(old).lstrip("/")
            if dest.exists():
                raise BuildError(
                    f"_data/redirects.yml: {old} would overwrite {dest.relative_to(out)}"
                )
            dest.parent.mkdir(parents=True, exist_ok=True)
            shutil.copyfile(legacy, dest)
            continue
        # … the HTML stub branch stays as it is …
```

```python
def slugify(text: str) -> str:
    return re.sub(r"[^a-z0-9]+", "-", text.lower()).strip("-")


def shift(html: str) -> str:
    """h3 -> h2, h4 -> h3; a heading without an id gets one from its text."""
    html = re.sub(r"<(/?)h3\b", r"<\1h2", html)
    html = re.sub(r"<(/?)h4\b", r"<\1h3", html)

    def add_id(m: re.Match[str]) -> str:
        level, attrs, inner = m.group(1), m.group(2), m.group(3)
        if "id=" in attrs:
            return m.group(0)
        return f'<h{level}{attrs} id="{slugify(_text(inner))}">{inner}</h{level}>'

    return re.sub(r"<h([23])([^>]*)>(.*?)</h\1>", add_id, html, flags=re.S)
```

```javascript
// Docs search on Pagefind's own pagefind.js, loaded on first use; no third-party UI (spec P3).
// The button stays hidden without JavaScript, so nothing on the page is dead.
(function () {
  var open = document.querySelector('[data-search-open]');
  var dialog = document.getElementById('docs-search');
  if (!open || !dialog) return;
  var input = dialog.querySelector('input');
  var list = dialog.querySelector('ol');
  var status = dialog.querySelector('[role=status]');
  var pagefind = null;
  var seq = 0;

  function show() {
    if (!dialog.open) dialog.showModal();
    input.focus();
  }
  open.hidden = false;
  open.addEventListener('click', show);
  dialog.querySelector('[data-search-close]').addEventListener('click', function () { dialog.close(); });
  document.addEventListener('keydown', function (e) {
    if (e.key !== '/' || e.ctrlKey || e.metaKey || e.altKey) return;
    var t = e.target;
    if (t.isContentEditable || /^(INPUT|TEXTAREA|SELECT)$/.test(t.tagName)) return;
    e.preventDefault();
    show();
  });

  input.addEventListener('input', async function () {
    var term = input.value.trim();
    var mine = ++seq;
    if (!term) { list.replaceChildren(); status.textContent = ''; return; }
    if (!pagefind) {
      pagefind = await import('/pagefind/pagefind.js');
      await pagefind.options({ highlightParam: 'highlight' });
    }
    var search = await pagefind.debouncedSearch(term);
    if (search === null || mine !== seq) return;  // a newer keystroke superseded this one
    var found = await Promise.all(search.results.slice(0, 8).map(function (r) { return r.data(); }));
    if (mine !== seq) return;
    list.replaceChildren.apply(list, found.map(function (d) {
      var li = document.createElement('li');
      var a = document.createElement('a');
      var p = document.createElement('p');
      a.href = d.url;
      a.textContent = d.meta.title;
      p.innerHTML = d.excerpt;  // Pagefind escapes our own page text and adds only <mark>
      li.append(a, p);
      return li;
    }));
    status.textContent = search.results.length
      ? search.results.length + (search.results.length === 1 ? ' result' : ' results')
      : 'Nothing found for “' + term + '”';
  });

  if (new URLSearchParams(location.search).has('highlight')) {
    import('/pagefind/pagefind-highlight.js').then(function () {
      new window.PagefindHighlight({ highlightParam: 'highlight' });
    });
  }
})();
```

the installed version and say so in the report.

```python
def write_feeds(out: Path, pages: list[Page], site: dict[str, Any], i18n: dict[str, Any]) -> None:
    """One Atom feed per language: every post under /<lang>/blog/<slug>/."""
    base = site["base_url"]
    for lang in site["languages"]:
        prefix = f"/{lang}/blog/"
        posts = sorted(
            (p for p in pages if p.url.startswith(prefix) and p.url != prefix),
            key=lambda p: str(p.meta["published"]),
            reverse=True,
        )
        if not posts:
            continue
        entries = "".join(
            "  <entry>\n"
            f"    <title>{html.escape(str(p.meta['title']).removesuffix(' | OpenWhistle'))}</title>\n"
            f"    <id>{base}{p.url}</id>\n"
            f'    <link href="{base}{p.url}"/>\n'
            f"    <published>{p.meta['published']}T00:00:00Z</published>\n"
            f"    <updated>{p.meta.get('modified', p.meta['published'])}T00:00:00Z</updated>\n"
            f"    <summary>{html.escape(str(p.meta['description']))}</summary>\n"
            "  </entry>\n"
            for p in posts
        )
        updated = max(str(p.meta.get("modified", p.meta["published"])) for p in posts)
        (out / lang.strip("/") / "blog" / "feed.xml").write_text(
```
